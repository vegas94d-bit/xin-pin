# 乒乓 · Пинг-понг

Браузерная игра «Пинг-понг» в одном файле `index.html`: тёмное поле в азиатском стиле, две ракетки, мяч и партия до 7 очков. Всё встроено (HTML + CSS + JS), внешних библиотек и интернета не требуется.

## Как открыть

Двойным щелчком по `index.html` — откроется в браузере. Сервер и сборка не нужны.
Работает в Chrome, Edge, Firefox и Safari, на компьютере и на телефоне.

## Как играть

На стартовом экране выберите режим:

- **Против ИИ** — три уровня сложности: Легко, Средне, Мастер.
- **На двоих** — один компьютер, две ракетки.

Затем нажмите «Начать партию». Побеждает тот, кто первым наберёт 7 очков.

## Управление

| Действие | Клавиши |
| --- | --- |
| Левая ракетка | `W` — вверх, `S` — вниз |
| Правая ракетка | `↑` — вверх, `↓` — вниз |
| Мышь / касание | ведите по своей половине поля |
| Пауза | `P` или `Space` |
| Рестарт | `R` |
| Меню | `M` |
| Звук вкл/выкл | `T` или кнопка «Звук» |

Угол отскока зависит от точки попадания по ракетке, мяч постепенно ускоряется. Лучший результат сохраняется в браузере (localStorage) отдельно для каждого режима и уровня сложности.
